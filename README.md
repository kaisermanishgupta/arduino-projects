# Arduino Projects

A collection of Arduino and NodeMCU-based projects developed during my B.Tech.  
These projects cover basic electronics, sensors, automation, embedded systems, and IoT concepts.

## 📁 Projects

| Project | Description |
|---|---|
| **Auto Street Light using LDR** | Automatically controls street lights based on ambient light intensity. |
| **Blink LED** | Basic Arduino LED blinking experiment. |
| **Blink 1 LED BT** | LED control using Bluetooth. |
| **Blink 2 LED** | Basic two-LED control experiment. |
| **Blink RGB LED** | RGB LED control and color generation. |
| **BT Control LED Arduino** | Controls an LED through Bluetooth using Arduino. |
| **BT LED Control** | Bluetooth-based LED control project. |
| **Buzzer** | Basic buzzer interfacing with Arduino. |
| **Disco Lights** | LED-based decorative/disco lighting effects. |
| **Distance Measurement using Ultrasonic Sensor** | Measures distance using an ultrasonic sensor. |
| **LCD Printing** | Displays information on an LCD using Arduino. |
| **LDR Buzzer Alarm** | Light-dependent buzzer alarm using an LDR sensor. |
| **LDR Control** | Controls output based on light intensity using an LDR. |
| **LED Button Control** | Controls an LED using a push button. |
| **LED Dimmer** | Controls LED brightness using PWM. |
| **NodeMCU – Home Automation System** | IoT-based home automation system using NodeMCU and Blynk. |
| **Servo Control** | Controls a servo motor using Arduino. |
| **Servo Control without Library** | Servo motor control implemented without using a dedicated servo library. |
| **Temperature & Humidity LCD (DHT11)** | Displays temperature and humidity readings from a DHT11 sensor on an LCD. |
| **Temperature Monitor (LM35)** | Temperature monitoring using an LM35 temperature sensor. |
